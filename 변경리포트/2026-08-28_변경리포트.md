# 2026-08-28 변경 리포트

## 국민설명회 일정 확인

- 기존 정부 계획과 보도에서는 **2026년 8~9월 대국민 설명회 개최 예정**으로 안내됐습니다.
- **2026-08-28 현재 정확한 날짜·시간·장소·참가 신청 방법을 담은 공식 공고는 확인되지 않았습니다.**
- 따라서 현 단계에서는 `8~9월 개최 계획`으로만 표기하고, 확정 일정처럼 안내하면 안 됩니다.

## 사이트 개선

- 메인 화면에 **제도화 로드맵** 탭을 추가했습니다.
- 법안 발의·병합 심사부터 본회의 통과, 공포, 시행 준비, 국민설명회, 하위법령 입법예고·확정, 본법 시행, 국가시험, 기존 종사자 전환 특례까지 10단계로 구분했습니다.
- 완료·진행·예정 상태를 색상으로 나누고, 확정 사실과 계획 단계 정보를 구별했습니다.
